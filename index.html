Project Highlights

Desktop Management System

Built with C# and Windows Forms to provide a focused desktop experience for construction site operations.

SQLite Persistence

Records are saved locally through Microsoft.Data.Sqlite and remain available between app sessions.

Security Awareness

Login is required, passwords are stored as SHA-256 hashes, and role permissions hide unavailable actions.

Role-Based Access

Admin
  • Can access all pages.
  • Can add, edit, delete, and view records.
  • Has full control over workers and reports.
Site Manager
  • Can access all pages.
  • Can manage projects, tasks, attendance, materials, and issue reports.
  • Can view and edit workers, but cannot add or delete workers.
Worker
  • Can access Dashboard, Tasks, and Issue Reports.
  • Tasks are view-only.
  • Can report and view issues, but cannot delete issue reports.

Technology Stack

C# / WinForms

Object-oriented Windows desktop application targeting net10.0-windows.

SQLite

Embedded database storage using an IAppDataStore interface and SqliteAppDataStore implementation.
